# Ideas

Things we've talked about and parked. Not a roadmap; a place to keep them.

- **Folding.** Collapse a card's thread behind it (a badge like "▸ 12"), unfold to bring it back
  exactly where it was. A view, not an edit: nothing moves or is deleted.
- **One idea, many boards.** Cards that live once in the library and appear on several boards, with
  backlinks showing where else they're used. The basis for search across boards and a graph view.
- **⌘K.** Search every board and run commands from one palette.
- **Change a card's kind.** Sticky ↔ note ↔ place, keeping text, threads and references.
- **Tags.** `#dora`-style tags in card text: shared themes across boards, clickable to find the rest.
- **Note templates.** Optional structures (a pattern, a decision record) without making any mandatory.
- **Reference types.** Optional kinds such as "supports" or "in tension with".
- **Save videos offline.** Keep a local copy of an X or YouTube video in the board's assets.
- **Omarchy themes.** Read Omarchy theme files directly, and follow the system theme on Linux.
- **Linux.** Eventually; the SwiftUI app is macOS-only today.
